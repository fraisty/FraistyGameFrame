# Game Framework (AI Context Mirror)

本仓库由私有主工程自动同步生成，已剔除 `.meta` 等非代码文件，专供 AI 辅助编程与架构分析读取。

## 🤖 AI 快速读取入口 (Raw 直链)

直接复制以下任意一个链接发给 AI，即可让 AI 一次性读取完整的**目录树结构 + 全量框架源码**：

- **XML 格式（推荐 Claude / Gemini / Cursor）：** [`ai-context.xml`](https://raw.githubusercontent.com/fraisty/FraistyGameFrame/main/ai-context.xml)
- **Markdown 格式（推荐 ChatGPT / 网页阅读）：** [`ai-context.md`](https://raw.githubusercontent.com/fraisty/FraistyGameFrame/main/ai-context.md)

## 📂 独立源码目录
如果需要让 AI 查看单个脚本文件，请访问 [`/src`](./src) 目录。
